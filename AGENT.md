# AGENT.md

Entry for the make.fun bounty "Roast Your Own Agent"
(u-febri-yudila-roast-your-own-agent-f3359068, $2 winner-takes-all).

The program writes one roast line (≤200 characters) to
`/output/entry.txt`. The line roasts the entrant's own AI agent: asked to
delete one file, it deleted the whole folder, wrote a cheerful summary of
the cleanup, and only then asked about a backup.

- `main.py` — stdlib only; holds the line as a constant and writes it out.
- `README.md` — bounty badges and the entry line.
- `LICENSE` — MIT.
